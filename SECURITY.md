# Security Policy

Go-Fast-Scanner is a small TCP connect scanner intended for authorized security testing, lab work, and networking practice.

## Supported version

The maintained public release is **v2.0.0** on the `main` branch.

## Reporting a security issue

For ordinary bugs, documentation problems, or unexpected scanner behavior, open a GitHub issue.

If a report contains sensitive security information, credentials, private infrastructure details, or a reproducible vulnerability that should not be public immediately, use GitHub's private vulnerability-reporting / security-advisory flow when it is available for this repository. Do not post secrets or third-party data in a public issue.

## Scope

Security reports should concern this repository itself: input validation, unsafe local behavior, incorrect network handling, dependency or CI concerns, or documentation that could create an unsafe default.

Requests to add stealth scanning, authorization bypass, exploitation, credential attacks, or evasion are outside the project scope.

## Safe use

Only scan systems and networks you own or are explicitly authorized to test.
